# @whippin/whatsapp-bot

The WhatsApp group scoreboard bot (issue #236): records Whippin share links as they arrive
in configured groups, posts each group's podium at its local time, reacts to shares, and
answers when addressed. See `AGENTS.md` for the design and `packages/infra/README.md` for
the deployment runbook (pairing, secrets, the test group).
